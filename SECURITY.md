# Security Policy

## Supported Versions

Generally, only the latest version of Shiptastic Integration for DHL has continued support. If a critical vulnerability is found in the current version of Shiptastic Integration for DHL, we may opt to backport any patches to previous versions.

## Reporting a Vulnerability

Shiptastic Integration for DHL is an open-source plugin for WordPress. Please report security bugs found in the source code of the Shiptastic Integration for DHL plugin through the [Patchstack Vulnerability Disclosure Program](https://patchstack.com/database/vdp/aedfb753-e047-4c76-a510-f93456dedb2c). The Patchstack team will assist you with verification, CVE assignment, and notify the developers of this plugin.
